React Tabs Component

A simple and responsive Tabs component built with React.

Features:

. Switch between different tabs
. Highlight the active tab
. Save the selected tab in Local Storage
. Restore the last selected tab after refreshing the page

Technologies:

. React
. JavaScript
. CSS
. Vite
. Local Storage
